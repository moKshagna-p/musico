# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-05-01

### Initial Release
- **Platform Launch**: Musico platform is now live for music discovery and social interaction.
- **Music Discovery**: Integration with Discogs API for comprehensive album search and metadata.
- **Social Features**: Rating systems, album reviews, and user following capabilities.
- **Personal Collections**: Support for custom lists (e.g., Listen Later).
- **Performance**: High-performance Bun/Elysia backend with intelligent caching.
- **Security**: Secure authentication and account isolation powered by Better Auth.
- **Professional Setup**: Modern TypeScript monorepo with Turbo, CI/CD, and professional documentation.
